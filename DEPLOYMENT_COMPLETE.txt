HOW TO USE
================================================================================

1. OPEN THE APPLICATION
   Browser: http://localhost:8080/

2. SEARCH FOR CUSTOMER
   - Enter phone number
   - Click "Search Customer"
   - System fetches data from CMS API

3. SELECT PRODUCTS
   - Choose products from the list
   - Enter quantities
   - Select order type (daily, weekend, alternate)

4. PLACE ORDER & MARK SALE
   - Click "Place Order & Mark Sale" button
   - System automatically:
     ✓ Places order via CMS API
     ✓ Generates route sheet via Voice API
     ✓ Updates database dates automatically
     ✓ Marks sale via Delivery API
     ✓ Inserts sales records

5. VERIFY COMPLETION
   - Status updates shown in real-time
   - Check server logs for details
