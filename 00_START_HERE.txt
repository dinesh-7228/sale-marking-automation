💾 HOW TO CHANGE DATABASE IN DBEAVER:

The system AUTOMATICALLY updates database dates, but to verify or manually change:

1. Open DBeaver
2. Connect to your MySQL database
3. Open SQL Editor
4. Copy-paste ONE of these queries:

   Update route sheet date:
   ─────────────────────────────────────────────────────────────
   UPDATE route_sheet_details 
   SET delivery_date = CURDATE() 
   WHERE customer_id = '9943824' 
   AND delivery_date > CURDATE();
   ─────────────────────────────────────────────────────────────

   Update order detail date:
   ─────────────────────────────────────────────────────────────
   UPDATE order_detail 
   SET start_date = CURDATE() 
   WHERE customer_id = '9943824' 
   AND STATUS = 'Y'
   AND start_date > CURDATE();
   ─────────────────────────────────────────────────────────────

5. Press Ctrl+Enter to run
6. Verify with SELECT query

⚠️  IMPORTANT: Replace '9943824' with YOUR customer DB_ID
