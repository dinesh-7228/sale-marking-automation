================================================================================
TROUBLESHOOTING
================================================================================

❌ "Port 8080 already in use"
   → Find process: lsof -i :8080
   → Kill it: kill -9 <PID>

❌ "Build fails"
   → Clear cache: rm -rf ~/.m2/repository/com/countrydelight
   → Rebuild: mvn clean package -DskipTests

❌ "Database connection error"
   → Verify credentials in DatabaseUtil.java
   → Ensure MySQL is running
   → Check network connectivity

❌ "API returns 400"
   → Verify authorization tokens are valid
   → Check request format
   → Review server logs
