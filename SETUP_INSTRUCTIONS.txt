QUICK START
================================================================================

1. START THE APPLICATION
   $ cd /home/dinesh/Documents/sale-marking-automation
   $ java -jar target/sale-marking-automation-1.0.0.jar

   OR (for background execution):
   $ nohup java -jar target/sale-marking-automation-1.0.0.jar > server.log 2>&1 &

2. OPEN IN BROWSER
   Open: http://localhost:8080/

3. ENTER CUSTOMER PHONE
   - Search for a customer by phone number
   - System will fetch customer details from CMS API

4. SELECT PRODUCTS
   - Choose products
   - Enter quantities
   - Select order type (daily, weekend, alternate, etc.)

5. CLICK "PLACE ORDER & MARK SALE"
   - System automatically executes 9-step workflow
   - All database updates happen automatically
   - No manual DBeaver operations needed!

2. API TOKENS
   File: src/main/java/com/countrydelight/api/ApiClient.java

================================================================================
THE 9-STEP AUTOMATED WORKFLOW
================================================================================

1. Customer Validation      - Verify customer exists
2. Place Order              - Call CMS API
3. Generate Route Sheet     - Call Voice API  
4. Fetch Route Sheet ID     - Query database
5. Update Route Sheet Date  - Change to TODAY (AUTO)
6. Update Order Date        - Change to TODAY (AUTO)
7. Mark Sale                - Call Delivery API
8. Insert Sales Records     - Batch insert with transactions
9. Verify Operations        - Confirm database updates

ALL AUTOMATED - NO MANUAL DBEAVER OPERATIONS!

================================================================================
TROUBLESHOOTING
================================================================================

Q: Application won't start
A: Check if port 8080 is in use

Q: API returns 400 Bad Request
A: Check authorization tokens are valid
   Review server logs for details

Q: Database operations not working
A: Verify credentials in DatabaseUtil.java
   Ensure tables exist with correct schema
