================================================================================
INTERACTIVE WORKFLOW API - ENDPOINTS SUMMARY
================================================================================

BASE URL: http://localhost:8080/api/workflow

================================================================================
STEP-BY-STEP FLOW ENDPOINTS
================================================================================

STEP 1: SELECT ENVIRONMENT
  POST /step1-environment
  Body: {"environment": "QA" | "UAT"}
  Response: Confirmation message

STEP 2: ENTER CUSTOMER NUMBER
  POST /step2-customer-number
  Body: {"customerNumber": "PHONE"}
  Response: Confirmation message

STEP 3: SEARCH CUSTOMER
  POST /step3-search-customer
  Body: (empty)
  Response: List of matching customers

STEP 4: GET CUSTOMER DETAILS
  POST /step4-customer-details
  Body: {"customerId": "ID"}
  Response: Customer details with city_id, franchise_id

STEP 5: CHECK ORDER STATUS
  POST /step5-check-order-status
  Body: {"orderAlreadyPlaced": true | false}
  Response: 
    - If false: Available products list
    - If true: Skip message (go to step 8)

STEP 6: SELECT PRODUCTS & PLACE ORDER
  POST /step6-place-order
  Body: {
    "products": [
      {
        "id": NUMBER,
        "quantity": NUMBER,
        "order_type": "daily" | "weekly" | "monthly"
      }
    ]
  }
  Response: Order confirmation

STEP 8: GENERATE ROUTE SHEET
  POST /step8-generate-route-sheet
  Body: (empty)
  Response: routeSheetId and details

STEP 9: UPDATE ROUTE SHEET DATE
  POST /step9-update-route-sheet-date
  Body: (empty)
  Response: Confirmation (date changed to TODAY)

STEP 10: UPDATE ORDER DETAILS DATE
  POST /step10-update-order-date
  Body: (empty)
  Response: Confirmation (date changed to TODAY)

STEP 11: MARK THE SALE
  POST /step11-mark-sale
  Body: {
    "latitude": OPTIONAL NUMBER,
    "longitude": OPTIONAL NUMBER
  }
  Response: Sale marked confirmation

================================================================================
COMPLETE WORKFLOW (ALL-IN-ONE)
================================================================================

COMPLETE WORKFLOW
  POST /complete
  Body: {
    "environment": "QA" | "UAT",
    "customerNumber": "PHONE",
    "customerId": "ID",
    "orderAlreadyPlaced": true | false,
    "products": [
      {
        "id": NUMBER,
        "quantity": NUMBER,
        "order_type": "daily"
      }
    ],
    "latitude": OPTIONAL NUMBER,
    "longitude": OPTIONAL NUMBER
  }
  Response: Complete workflow result with all steps

================================================================================
UTILITY ENDPOINTS
================================================================================

GET WORKFLOW STATE
  GET /state
  Body: (empty)
  Response: Current workflow state

RESET WORKFLOW
  POST /reset
  Body: (empty)
  Response: Confirmation (state reset)

================================================================================
RESPONSE FORMAT
================================================================================

SUCCESS RESPONSE:
{
  "success": true,
  "message": "Description of action",
  "data": { ... },
  "nextStep": "Next action to take"
}

ERROR RESPONSE:
{
  "success": false,
  "message": "Error description"
}

================================================================================
QUICK CURL EXAMPLES
================================================================================

1. COMPLETE WORKFLOW (RECOMMENDED)
curl -X POST http://localhost:8080/api/workflow/complete \
  -H "Content-Type: application/json" \
  -d '{
    "environment": "QA",
    "customerNumber": "9876543210",
    "customerId": "12345",
    "orderAlreadyPlaced": false,
    "products": [{"id": 114, "quantity": 2}]
  }'

2. STEP 1: ENVIRONMENT
curl -X POST http://localhost:8080/api/workflow/step1-environment \
  -H "Content-Type: application/json" \
  -d '{"environment":"QA"}'

3. STEP 3: SEARCH CUSTOMER
curl -X POST http://localhost:8080/api/workflow/step3-search-customer \
  -H "Content-Type: application/json"

4. GET WORKFLOW STATE
curl http://localhost:8080/api/workflow/state

5. RESET WORKFLOW
curl -X POST http://localhost:8080/api/workflow/reset \
  -H "Content-Type: application/json"

================================================================================
WORKFLOW SCENARIOS
================================================================================

SCENARIO 1: ORDER NEEDS TO BE PLACED
  orderAlreadyPlaced: false
  Flow: Steps 1-2-3-4-5(fetch products)-6-8-9-10-11
  Duration: Full process

SCENARIO 2: ORDER ALREADY EXISTS
  orderAlreadyPlaced: true
  Flow: Steps 1-2-3-4-5(skip 6)-8-9-10-11
  Duration: Shorter (skips product selection & order placement)

SCENARIO 3: SINGLE API CALL
  Use /complete endpoint with all parameters
  Duration: Instant (no sequential calls needed)

✓ Comprehensive error handling
✓ API integration for all external services
✓ Both interactive and batch processing

DATABASE UPDATES (AUTOMATIC)

  - Changes: Tomorrow → Today

STEP 10: Order Details Date
  - Table: order_details
  - Field: order_start_date
  - Changes: Tomorrow → Today

After Sale Marking: Sales Records
  - Automatic insertion of sales data
  - No manual intervention needed
